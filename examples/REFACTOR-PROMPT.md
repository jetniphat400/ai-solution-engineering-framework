# Architecture Assessment and Refactoring Prompt

Read `AGENTS.md` and use Architecture Assessment and Refactoring Mode.

Analyze the current codebase before editing. Identify structural smells, duplicated business rules, hardcoded environment values, mixed responsibilities, dependency problems, test gaps, and operational risks.

Propose the simplest target architecture that fixes the verified problems. Consider MVC, layered architecture, modular monolith, clean or hexagonal architecture, and microservices only when independently justified.

Produce an architecture assessment and incremental refactoring roadmap. Do not perform a big-bang rewrite.
